An interactive, animated Sudoku Solver web app built with Flask (Python) on the backend and HTML, CSS, JavaScript on the frontend.
Enter any Sudoku puzzle, click Solve, and watch the solver fill in the grid step-by-step with smooth animations.

✨ Features

✅ Interactive Sudoku Grid – Type numbers directly into the cells
<br>
✅ Animated Solution Filling – Solved numbers fade in with color highlights
<br>
✅ Backend Powered by Python – Uses backtracking algorithm to find solutions
<br>
✅ Frontend in HTML, CSS, JS – Clean, modern UI with responsive design
<br>
✅ Reset Option – Clear the board instantly and try a new puzzle
<br>
✅ Handles Impossible Puzzles – Displays an error if no solution exists
<br>

🛠️ Tech Stack

Backend: Python
<br>
Algorithm: Backtracking Sudoku solver
<br>
Frontend: HTML5, CSS3 (Animations), Vanilla JavaScript
<br>
Communication: AJAX (Fetch API)
<br>

Run procedure:
<br>
python app.py
